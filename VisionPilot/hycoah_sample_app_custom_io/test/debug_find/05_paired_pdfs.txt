1854-1.2.3. JobContainer
1855-JobContainer class stores a sequence of Jobs, and is meant to be pushed to the HWA Execution
1856-Framework so the jobs are enqueued and executed by the HWA.
1857-In a JobContainer, several jobs (up to a maximum of 16) can be added using an add method for
1858:each type of job or using the add_paired method for the paired jobs. Paired jobs must start together
1859-on the hardware and will be able to use the Wake-Up and Sleep features in their command lists
1860-(for IMPX jobs only).
1861-To specify the scheduling of the jobs, the jobs are added with a dependency vector set by the user
1862-app, containing the ids of every job (from the same container) that need to be finished for the
1863-currently added job to be launched.
